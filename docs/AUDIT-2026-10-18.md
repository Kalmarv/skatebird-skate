- **Exact spawn height/yaw**: `Spawn::AtWithHeight` fixed the level3/4/7 "starts on the ceiling" bug (marker snapped to topmost surface), commit e45e60f; coordinate mapping Unity (x,y,z) -> scene (x,y,-z), **scene yaw = (180 - unity yaw)**, verified on the bedroom (KNOWLEDGE.md).
- **Isolated game copy** (`ds-modding/game`: junctions for `Data`/`__Installer`, own `Mods/`, own `logs/`, own `LOCALAPPDATA` per run) so tests never touch Caleb's 55-mod install (which shows a black HUB). - **Camera parity method**: BepInEx 5 plugin in the lab copy teleports the bird and sets `Camera.main` to `Euler(pitch, cam_yaw, 0)` re-asserted every frame (Cinemachine fights it); with `cam_yaw = pose yaw` the measured bearing equals the pose yaw to 0.00° on all 8 levels (`out/skatebird_spawn_refs.json`); skate's camera converges to the spawn marker yaw after ~30-45 s. SkateBIRD's dev console has only `MissionManager.LoadLevel`.
- **Finding the alpha defect with the right oracle**: UnityPy 1.25.4 audit of stored properties/pass state (`tools/audit_material_alpha.py`, `out/alpha-audit-level4.json`): `CardboardBox_mat` (sharedassets1.assets:18) and `Black rubber` (sharedassets0.assets:341) are Standard opaque (One/Zero) with an additive ForwardAdd pass; primase `lower.rs::blends` treated any additive pass as a blend. Repair `2013740c`/`1decdbef` (draw pass chosen by pipeline; `m_ShaderKeywords` for 2019.4; pass kinds): rooftop 55 blend/7 opaque/3 mask -> 26/36/3 (material-table entries), solid quarter-pipe/brick wall/ramp restored in game (job 73cde79a, `out/alpha-fix/compare_level2.png`).
- **Proving UV loss** with one number: office `Desk surface` (sharedassets1.assets:117) has base scale (0.1, 0.1) but the exported UV arrays were unchanged (`tools/prove_uv_loss.py` -> `out/office-uv-loss-proof.json`); producer = private `bake_texture_transforms` refusing mixed transforms, then the program's `clear_texture_transforms` erasing them. Fix = base-first bake with counted secondary-slot loss (`program/src/uv_policy.rs`, `variants.rs`).
- **Vertex-colour trace** through the real Houdini/SpecularVertexColor ForwardBase DXBC: material colour x COLOR0; the target builder drops COLOR_0 unless `lower-tint-reskate` is composed; do not enable globally (9 Standard + 2 Legacy prims also carry non-white COLOR_0 that their shaders ignore) (`out/office-color-semantics.json`). Agreed core design: `core.vertex_color {Ignored}` + producer tables (gate/vertex-color).
- **Dark-wood normal bug**: Standard must use base 0.1 tiling for bump; DXT5nm trace found no green inversion, so *do not flip normals blindly* (`out/bedroom-normal-trace.json`, unity-reader verified exact 2019.4.20f1 shader source, `ext/builtin-2019.4.20f1`).
