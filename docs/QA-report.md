- All eight `build.log`/`compile.log` pairs finished; no error lines, every compile reported `Native map package complete` and every level has `stage/Patch`.
- level12 (playground) has 0 punctual lights. Its Unity scene has 2 active directional lights (3 more are conditioned out); skate lights itself by time of day, so 0 written lights is the designed behaviour, not a missing export.
